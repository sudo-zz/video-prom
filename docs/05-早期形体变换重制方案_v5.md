# v5 宣传片重制方案

状态：用户已于 2026-11-09 确认，现已完成制作和本机验证。下文保留制作依据，交付文件与检查结果见 `优化版_v5/使用说明.md`。

## 设计判断

这一版围绕“一张消息卡的往返”展开。观众从输入问题开始，持续跟随同一个容器，看到它完成脱敏、外发、接收回复和本地还原。小网关是这段往返的空间锚点。

现有母版为输入、外发、云端回复和内网还原分别创建了卡片，依靠淡出、淡入衔接。画面切换时，信息的位置、尺寸和背景同时改变，阅读需要重新开始。持续缩放、移动颗粒和光效又分散了注意力。导出脚本采用 30fps、每帧单次采样，快速位移时缺少运动模糊。

参考 [Prompt Motion 的形体变换案例](https://prompt-motion.com/twoclipping-5cba86)，采用同一主体连续变形、统一弹簧响应、独立安排文字进退场和逐帧采样的方法。内容改为网关的数据往返流程；容器的变化由实际操作和处理阶段推动。

## 画面方向

主背景为暖白 `#F5F5F3`，文字为石墨黑 `#1D1D1F`，网关以银铝材质和柔和接触阴影呈现。留白围绕当前信息展开，减少同时出现的标签。琥珀和绿色分别用于外发及还原状态，使用范围限于指示灯和必要的数据标记。

机身保留已确认的无 Logo 正面、右侧单枚状态灯和内缩黑底座。通过轮廓、表面明暗及落地阴影表达材质。取消全屏日食、星点、光束和反复铺屏转场。每个状态保留一句短说明，技术细节直接体现在消息卡中。

镜头只在识别敏感字段、观察还原和片尾展示硬件时移动。阅读阶段允许画面稳定。横屏采用左右往返路径，竖屏改为上下路径，并重新安排字号及换行。

## 36 秒分镜

以 120 BPM 的半秒节拍作为动作对齐基准。下表规定信息顺序和停留时间，具体弹簧响应在关键帧预览后调整。

| 时间 | 同一主体的变化 | 观众需要看清的内容 |
| --- | --- | --- |
| 0–3 秒 | 圆角胶囊展开为提问卡，光标完成输入并点击发送 | 知识库负载异常，需要检查连接信息 |
| 3–6 秒 | 卡片推近，三个敏感字段依次被识别 | 账号、密码、内网地址；排障参数保留 |
| 6–10 秒 | 字段沿短路径进入网关，本来位置长出一致占位符 | 真实凭据留在本地，问题上下文仍然可读 |
| 10–13 秒 | 卡片收窄为报文，经过网关，带着锁定状态进入传输段 | 脱敏后再经 TLS 加密外发 |
| 13–16 秒 | 报文在云端位置展开为同一张卡 | 云端看到的占位符和完整排障参数 |
| 16–22 秒 | 卡片向下扩展，生成两条检查命令 | 两条 `psql` 命令沿用同一组占位符；先检查连接状态与活跃查询 |
| 22–26 秒 | 命令卡沿原路径回到网关，六处占位符对应还原 | 同一账号、密码和地址在两条命令中恢复一致 |
| 26–29 秒 | 返回卡稳定落位，光标点击复制 | 返回可供复制的命令 |
| 29–31 秒 | 本地映射抽屉清零、收起，状态灯回到待机 | 会话结束，映射清除 |
| 31–36 秒 | 卡片收拢，镜头自然靠近原来的硬件 | 产品名与“让 AI 看懂问题，但看不见秘密。” |

文案保留已有研发案例的结构，账号、密码及地址统一使用明确标注的虚构演示值，不增加性能承诺。旧版将 `idle_timeout=0` 直接判为根因，当前材料不足以支持这个结论；本版改为展示检查步骤。片尾不沿用缺少验证依据的“100% 推理零折损”“5 分钟接入”等数字。

## 动画与导出

复用现有 HTML 确定性渲染方式、硬件 SVG、浏览器抽帧和 Swift 编码能力。主卡片使用同一个容器，连续计算位置、尺寸与圆角；转场内容在自己的进退场窗口内替换，避免叠字。移动先启动，形变随之完成，落位后才进入主要阅读段。

采用统一的高阻尼弹簧和连续轨迹。去掉相机的周期性漂移、颗粒抖动及大范围 `will-change`。文字在稳定阶段保持清晰，短暂模糊仅用于内容切换。

目标输出为原生 60fps。快速运动段每帧采样四个子帧，合成适度的运动模糊；静止阅读段使用清晰画面。合成沿用本机能力，不安装全局依赖。

声音采用轻量原创节拍和发送、替换、复制等短音效，无旁白。静音播放也应完整表达业务流程。

## 交付与检查

交付横屏 `1920×1080`、竖屏 `1080×1920` 两支 36 秒、60fps MP4，以及可离线预览的 HTML 母版、分镜预览和重制说明。新增文件放入 `优化版_v5/`，路径规则见 `proj.md`。

先完成横竖屏的状态关键帧和主要转场预览，检查文字、形体和空间关系，再输出全片。全片完成后检查：

- 同一时间点重复渲染和乱序访问，画面是否一致。
- 转场是否出现位置跳变、内容闪现、叠字或裁切。
- 外发和云端阶段是否只展示脱敏数据；上下文及参数是否保留。
- 两条命令中的六处占位符是否一致还原。
- MP4 是否为预期尺寸、60fps、2160 帧和 36 秒，并能正常解码播放。
- 横屏和竖屏完整播放时，阅读时间及运动节奏是否合适。

所有新增说明和片中文字均按 [humanizer-zh](https://github.com/op7418/humanizer-zh/blob/main/SKILL.md) 检查表达，保留事实、条件和确定程度。
