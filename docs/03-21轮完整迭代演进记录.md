      1. **根除 60Hz 跨 Worker 合成器瓦片亚像素相位震颤**：通过 Swift 逐像素比对 v10 渲染帧发现，虽然单页 DOM 坐标恒定，但 `will-change: transform` / `translate3d` 会令 Chromium 将图层光栅化瓦片缓存在各页面最后一次重绘时的亚像素偏移相位上；6 个并发 Worker 轮询截帧（`idx = nextFrame++`）导致相邻帧在 6 组不同亚像素相位间以 60Hz 高频切换（单帧最多 `61,733` 像素跳变，`maxDelta = 217`）。在 v11 中彻底移除全部 `will-change`、`backface-visibility: hidden`、`translate3d` 与 CSS `filter`，定位统一改用整数 `left/top/width/height` + 到位归零 `transform: none`，并将 `film_capture.cjs` 改为按连续帧块顺序渲染，跨页像素差异归零（`diffPx = 0`）。
      2. **消除指数长尾蠕动、顶栏进位微移与半像素边框**：将 `springStep` 升级为有限时长 `C²` 五次多项式（精确落定 `1`）；将 `#msVal` 拆分为固定宽右对齐 `#msNum`（`38px`）；将 `1.5px` 半像素边框统一为整数像素边框，固定打字光标行盒高度，恒定 `#stage` 背景 `#f5f5f7` 与网关指示灯稳态光晕。
      3. **消除 H.264 编码 B 帧与短 GOP 量化呼吸**：升级 `capture_encode.swift` 关闭 B 帧重排（`AVVideoAllowFrameReorderingKey: false`）、采用 `10s` GOP 与 `8.5~9.0 Mbps` 码率。静止帧因 100% 一致直接编码为零残差 `P_SKIP` 宏块，双端 MP4 体积反而降至 `15 MB` / `14 MB`，经 `AVAssetReader` 对编码后 `.mp4` 逐帧解码实测：**`frozenJitterFrames = 0, maxFrozenDelta = 0`**。
